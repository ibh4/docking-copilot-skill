# 科学限制（SCIENTIFIC LIMITATIONS）

本文件与每次运行生成的 `reports/result.md` 中的限制声明（固定措辞，
实现于 `backend/app/services/interpretation_service.py`）保持一致。
**任何基于本工具输出得出的结论都必须先阅读本节。**

## 1. 打分不是自由能，更不是药效

- Vina `affinity` 是**经验打分函数与构象搜索的结果**，不是实验结合自由能；
- 不能由分数换算或直接推断 Kd、Ki、IC50；
- 分数排序 ≠ 活性排序，更不构成任何药效、毒性或成药性结论；
- 打分函数对特定化学空间（金属配位、共价结合、强电荷相互作用等）
  存在系统性偏差。

## 2. 刚性受体近似

- 受体在整个过程中被视为**刚性**：不考虑诱导契合、侧链重排、
  主链运动与蛋白柔性；
- 不考虑显式溶剂效应（水分子默认被移除，除非显式 `keep_waters`）；
- 对结合伴随大构象变化的靶点（如激酶 DFG-in/out 转换），
  结果可能严重偏离真实情况。

## 3. 质子化与状态建模的局限

- 质子化状态采用**工具默认策略**（`protonation_policy=tool_default`），
  未做 pH 显式建模；
- 组氨酸互变异构、酸性/碱性残基的局部 pKa 偏移均未处理；
- 配体的互变异构/立体化学由 RDKit 默认规则处理，
  输入 SMILES 未显式指定时可能与生理状态不符。

## 4. 对接盒（box）带来的偏差

- box 定义搜索空间：**真实结合位点不在 box 内时，得到的"最优 pose"
  没有意义**；
- box 过小会截断合理构象，box 过大会稀释采样密度；
- `reference_ligand` 模式的盒中心来自共晶配体，若共晶配体本身
  不代表目标结合模式，会引入定位偏差。

## 5. 构象搜索与 pose 不确定性

- 构象搜索是启发式的：多个 pose 分数接近（< 1 kcal/mol）时
  **无法区分**，top-1 不一定代表真实结合模式；
- `rmsd_lb/ub` 是 Vina 内部自参照量，不是对任何实验结构的 RMSD；
- 配体 3D 构象来自 ETKDGv3 + 力场优化，柔性大分子的初始构象
  覆盖可能不足。

## 6. 跨体系不可比

以下任一条件不同，分数**不可横向比较**：

- 不同受体（包括同一受体的不同链选择/清洗策略）；
- 不同 box（位置或大小）；
- 不同质子化状态；
- 不同 Vina 参数（exhaustiveness、seed、energy_range 等）。

批次内比较指标（雷达图等）全部是展示性归一化，公式与前提见
`RESULT_INTERPRETATION.md`。

## 7. 定位：假设生成与排序，不替代实验

- 本流程输出用于**假设生成、候选排序与教学演示**；
- 任何进入湿实验、临床或产品决策的结论，必须由实验验证；
- 报告中的所有"建议"措辞均不得被引用为药效证据。
