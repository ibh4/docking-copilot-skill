## 示例 docking box 依据

`examples/inputs/*.json` 中的搜索盒：

- `center = [18.3, 2.3, 21.4]`：取受体全部 ATOM 的几何中心并四舍五入到
  0.1 Å，作为无先验结合位点信息时的保守默认中心（仅用于演示流程，
  不代表真实结合位点）；
- `size = [20, 20, 20]` Å：单边处于配置约束 [10, 30] Å 之内，
  体积 8000 Å³ < 上限 27000 Å³；
- `seed = 42`、`exhaustiveness = 8`、`num_modes = 9`：与
  `backend/app/config.py` 中的默认值一致，保证示例可复现。

## 许可与限制

该结构仅用于 Skill 演示与测试。docking 分数是打分函数的相对排序指标，
不构成真实药效或精确结合自由能结论（见 `docs/SCIENTIFIC_LIMITATIONS.md`，
后续任务补齐）。
